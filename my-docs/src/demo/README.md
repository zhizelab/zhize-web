# 关于智泽实验室

智泽实验室隶属于河海大学，聚焦人工智能与机器人技术的交叉研究，致力于将前沿算法转化为解决实际问题的工程能力。

## 研究方向

- **机器人自主导航** — 基于 ROS 的 SLAM 建图、路径规划与视觉伺服
- **计算机视觉** — 目标检测、图像分割、3D 点云处理
- **深度学习应用** — 大语言模型、知识图谱、智能问答系统
- **物联网与边缘计算** — 嵌入式部署、传感器网络、实时数据处理
